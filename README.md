# Motion Market

A responsive marketplace prototype for the Motion Only community.

## Included

- Public product catalogue with search and category filters
- Separate public and Motion Only member prices
- Simulated membership verification flow
- Product detail views
- Seller listing preview flow
- Responsive layouts for desktop and mobile

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## Production roadmap

The current site is a front-end prototype. A production release will need authentication shared with Motion Only, a database, image uploads, moderation, secure checkout or enquiries, and server-side validation of member pricing.
